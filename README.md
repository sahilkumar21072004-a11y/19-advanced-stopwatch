# ⏱ Advanced Stopwatch (HTML • CSS • JavaScript)

## 📌 Project Overview

The **Advanced Stopwatch** is a modern, real-time web application designed using  
**HTML5, CSS3, and Vanilla JavaScript** that provides precise time tracking with  
**milliseconds accuracy, lap recording functionality, keyboard controls, and a glass-style UI**.

Unlike basic stopwatch implementations, this project focuses on:

- High-precision **time measurement**
- Clean and responsive **modern user interface**
- Interactive **lap tracking system**
- Efficient **JavaScript timing logic**
- Portfolio-level **frontend engineering quality**

This makes the project a strong **intermediate-level frontend showcase** suitable for:

- GitHub portfolio presentation  
- Internship applications  
- Academic submissions  
- Frontend skill demonstration

## ✨ Key Features

### ⏱ Real-Time Millisecond Precision
- Displays **minutes, seconds, and milliseconds**
- Uses optimized **JavaScript timing functions**
- Ensures **smooth and accurate updates**

### 🏁 Lap Timer System
- Records **multiple lap times**
- Displays laps in **reverse chronological order**
- Demonstrates **dynamic DOM rendering**

### 🎮 Keyboard Controls
Supports productivity-focused shortcuts:

- **Spacebar** → Start / Pause  
- **L key** → Record lap  
- **R key** → Reset stopwatch  

This mimics **real professional stopwatch tools**.

### 🎨 Modern Glassmorphism UI
- Blurred **glass card design**
- Smooth **hover and transition effects**
- Minimal **dark theme aesthetic**
- Clean **typography and spacing**

### 📱 Fully Responsive Layout
- Optimized for **desktop, tablet, and mobile**
- Uses **Flexbox and modern CSS layout techniques**

### ⚡ Efficient State Management
- Proper handling of:
  - Start / Pause state  
  - Reset behavior  
  - Lap storage  
- Demonstrates **clean JavaScript architecture**
